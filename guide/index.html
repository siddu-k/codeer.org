How to Use Codeer

Codeer is a decentralized, static knowledge platform. This guide explains how to read, create, and contribute content.

Contribution Workflow

1

Visit the Creation Hub

Go to the Create page. This is your toolbench for generating new content without writing raw HTML boilerplate.

2

Generate Content

For Articles: Use the WYSIWYG editor to write your guide. It supports code blocks, headers, and lists. Click "Generate" to download a fully styled .html file.

For Profiles/Projects: Download the "Starter Template" files. Edit them locally to add your specific details.

3

Commit & Push

Place your generated file in the correct directory (e.g., articles/content/cloud/aws/). Commit the file to your branch and submit a Pull Request on GitHub.

Standards

CSS Variables

We use a custom property system. Refrain from using inline hex codes; use var(--bg-card), var(--accent) etc.

Icons

No emojis in UI elements. Use Lucide Icons via the <i data-lucide="name"></i> tag.

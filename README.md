# Codeer Platform

**Codeer** is a static, open-source community knowledge platform built for developers. It features a decentralized content model where every article, profile, and project is a standalone HTML file.

## 🌟 Features

- **No Backend**: 100% static HTML/CSS/JS. Deploys anywhere (GitHub Pages, Vercel).
- **Client-Side Generation**: Create articles directly in the browser and download the file.
- **Deep Categorization**: Structured knowledge paths for Cloud, AI, Software, and Web3.
- **Privacy First**: No tracking, no cookies, no login walls.

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/siddu-k/codeer.git
   ```
2. **Open `index.html`** in your browser.

## 📂 Structure

- `index.html`: Landing page.
- `home.html`: Main dashboard.
- `create.html`: Content generator.
- `articles/`: Technical guides and tutorials.
- `projects/`: Community project showcase.
- `assets/`: Shared styles and scripts.

## 🛠 Tech Stack

- **HTML5**: Semantic structure.
- **CSS3**: Custom property-based architecture (`main.css`, `components.css`).
- **JavaScript**: Native ES6 modules.
- **Lucide**: Professional SVG iconography.

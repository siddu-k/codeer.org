# Contributing to Codeer

We welcome contributions from the community! Codeer is built on the principle of "Content as Code".

## How to Contribute

### 1. Articles
1. Go to `create.html` in your local setup.
2. Select "New Article".
3. Fill out the content and click "Generate".
4. The file will download. Place it in the appropriate directory (e.g., `articles/content/software/python/`).
5. Submit a Pull Request.

### 2. Projects & Profiles
- Create a new HTML file in `projects/` or `profiles/` using the provided templates.
- Ensure you link to the global `assets/css/main.css`.

## Style Guide

- **Icons**: Use [Lucide Icons](https://lucide.dev/).
- **CSS**: Use variables from `main.css` (`--accent`, `--bg-card`, etc.).
- **Code**: Keep HTML clean and semantic.
